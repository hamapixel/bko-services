# Frontend BKO Services

Squelette Next.js (App Router, TypeScript et Tailwind CSS). Les espaces client,
prestataire et administration seront développés aux étapes prévues dans
`../docs/architecture.md`.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Ouvrir `http://localhost:3000`. Pour vérifier le build : `npm.cmd run build`.
